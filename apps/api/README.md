# @sitepix/api

HTTP API + domain services for SitePix.

## Packages

| Import | Purpose |
|--------|---------|
| `@sitepix/api` | Domain services + schemas |
| `@sitepix/api/http` | `/v1/*` handlers (server-only) |
| `@sitepix/api-client` | Typed client used by `apps/web` |

Web UI lives in **`apps/web`**. Plan: [`docs/plan.md`](../../docs/plan.md).
