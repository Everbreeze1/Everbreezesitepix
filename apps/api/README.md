# @everlumen/api

HTTP API + domain services for Everlumen.

## Packages

| Import                  | Purpose                         |
| ----------------------- | ------------------------------- |
| `@everlumen/api`        | Domain services + schemas       |
| `@everlumen/api/http`   | `/v1/*` handlers (server-only)  |
| `@everlumen/api-client` | Typed client used by `apps/web` |

Web UI lives in **`apps/web`**. Plan: [`docs/plan.md`](../../docs/plan.md).
